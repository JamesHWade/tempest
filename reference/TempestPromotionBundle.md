# A deterministic Tempest evidence-promotion proposal

A deterministic Tempest evidence-promotion proposal

## Usage

``` r
TempestPromotionBundle(
  schema_version = integer(0),
  bundle_id = character(0),
  schema_build_digest = character(0),
  research_run_id = character(0),
  min_support_score = integer(0),
  research_manifest = list(),
  stage_records = list(),
  proof = list(),
  claim_ids = character(0),
  records = list()
)
```
