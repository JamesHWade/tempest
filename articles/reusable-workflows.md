# Tempest 0.2 generic-kernel cutover

The experimental application-neutral workflow, runtime, capability,
connection, skill, deliverable, artifact, and host-state APIs are
unavailable in Tempest 0.2. Retained symbols fail immediately with class
`tempest_generic_kernel_cutover_error`. There is no compatibility or
migration layer.

Use
[`tempest_run()`](https://jameshwade.github.io/tempest/reference/tempest_run.md)
for scripted STORM research and
[`tempest_session()`](https://jameshwade.github.io/tempest/reference/tempest_session.md)
for interactive Co-STORM research. Fixed scientific transformations
carry dsprrr program identity, and open-ended agent work carries Deputy
execution identity. Those identities support correlation and audit joins
only; they do not claim causal content provenance.

This non-runnable vignette remains only as deletion inventory until T8
removes the generic kernel physically. It is intentionally excluded from
the pkgdown article navigation.
